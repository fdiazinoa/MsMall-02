MSMALL Audit Systems

Presentación de Funcionalidades del Sistema

Versión: MVP ACTIVO v1.2.0

Arquitectura: React SPA + FastAPI + PostgreSQL

Tipo: Plataforma SaaS de Auditoría y Control de Ventas

📊 1. Dashboard BI (Business Intelligence)

El módulo principal del sistema proporciona una vista ejecutiva de los indicadores clave de rendimiento del mall.

Funcionalidades Principales:

KPIs en Tiempo Real
  • Ventas Brutas: Ingresos totales del período seleccionado
  • Transacciones: Número total de operaciones registradas con tendencia porcentual (+2.4%)
  • Ticket Promedio: Valor promedio por transacción con análisis comparativo (-1.2%)
  • Ventas Netas: Ingresos después de descuentos e impuestos
Análisis Visual
  • Tendencia de Ventas Diarias: Gráfico de líneas mostrando el comportamiento de ventas en los últimos 7 días
  • Top 5 Locales: Ranking de los establecimientos con mejor desempeño
Controles de Filtrado
  • Selector de Mall (Ej: Megacentor Mall)
  • Rango de fechas configurable (01/02/2026 - 06/02/2026)
  • Sistema de estado operativo en tiempo real

🔄 2. Importación FTP/SFTP Automatizada

Sistema de integración automatizada con servidores externos para la importación de datos de ventas.

Capacidades del Módulo:

Gestión de Conexiones Múltiples
  • Configuración independiente por establecimiento (Skechers, Aldo, American Eagle, Calvin Klein, LC Waikiki, Puma)
  • Soporte para protocolos SFTP (SSH) y FTP estándar
  • Puerto personalizable (configuración por defecto: 2022)
Configuración por Conexión
  • Servidor: Hostname y directorio remoto
  • Formato de Archivo: Especificación de extensión (.txt, .csv)
  • Mapeo Dinámico: Vinculación de columnas fuente con campos del sistema
    • total neto, comprobante, fecha venta, cajero, referencia
  • Programación: Última ejecución registrada con timestamp
Operaciones Disponibles
  • Creación de nueva conexión
  • Edición de configuración de mapeo
  • Ejecución manual inmediata ("Ejecutar Ahora")
  • Eliminación de fuentes de datos
  • Estado activo/inactivo

📈 3. Auditoría de Ventas (Compliance Matrix)

Módulo de control y seguimiento de cumplimiento en la entrega de información financiera.

Características Principales:

Matriz de Cumplimiento
  • Visualización tabulada de 10+ locales registrados
  • Clasificación por categoría (FASTFOOD, ZAPATERÍA, VESTUARIO, ROPA, etc.)
  • Estado crítico visual mediante etiquetas de alerta
Indicadores de Cumplimiento
  • Estado: Crítico/Aceptable/Óptimo
  • Días Faltantes: Contador de días sin reportar (Ej: 6 de 6 días)
  • Porcentaje de Cumplimiento: 0% - 100%
  • Acción: Botón "Auditar" para revisión detallada
Herramientas de Análisis
  • Filtros por rango de fechas (Desde/Hasta)
  • Selector multi-local o "Todos los Locales"
  • Exportación en formatos Excel y PDF
  • Actualización manual de datos
Resumen Ejecutivo
  • Ventas Totales (Neto): $0.00
  • Locales Auditados: 0
  • Malls Reportando: 0

🏪 4. Mantenimiento de Locales

Gestión completa de la configuración contractual y física de los establecimientos comerciales.

Funcionalidades del Módulo:

Tabla de Gestión de Locales 10 locales registrados
  • Información Local:
    • Nombre comercial e ID único
    • Icono de categoría visual
    • Clasificación por rubro (FASTFOOD, RETAIL, ZAPATERÍA, etc.)
  • Responsable:
    • Nombre del encargado del local
    • Datos de contacto asociados
  • Ubicación:
    • Piso específico (P1, P3)
    • Asociación con Mall (Mall Plaza)
  • Métricas Contractuales:
    • Mts²: Superficie del local (rango: 20-150 m²)
    • Renta %: Porcentaje de renta variable sobre ventas (2%-5%)
Operaciones Disponibles
  • Búsqueda por nombre, responsable o código
  • Registro de nuevo local
  • Edición de información existente
  • Eliminación de registros
Zona de Peligro (Administrador)
  • Funcionalidad restringida para reiniciar base de datos de ventas
  • Advertencia visual de alta prioridad

💰 5. Gestión Financiera (Salud Financiera)

Análisis avanzado de OCR (Occupancy Cost Ratio) y proyecciones de recaudación.

Componentes del Dashboard:

Métricas Clave
  • Venta Prom m² Mall: $0.00 - Ingreso promedio por metro cuadrado
  • Locales en Riesgo (OCR > 20%): 0 Locales - Identificación de establecimientos con alto costo de ocupación
Gráfico de Salud de Cartera
  • Análisis comparativo: Ventas vs OCR por establecimiento
  • Línea de referencia visual: "RIESGO 20%" (umbral crítico)
  • Comparativa de 9 locales simultáneos:
    • Pollo Victorina, Sketchers, Aldo, American Eagle, Calvin Klein, LC-Waikiki, Puma, Sportline, Cafe Santo Domingo, Bath & Body
Proyección de Recaudación (Variable)
  • Tabla de estimación mensual de renta variable
  • Columnas: LOCAL | VENTA ACTUAL | PROYECCIÓN | RENTA VAR. EST.
  • Indicador de estado: "No se proyecta cobro de renta variable este mes"
Controles de Exportación
  • Selector de rango de fechas (01/02/2026 - 28/02/2026)
  • Exportación Excel (botón verde)
  • Exportación PDF (botón rojo)

🔐 Seguridad y Arquitectura

Autenticación

  • Sistema de login basado en Supabase
  • Roles y permisos granulares
  • Sesiones persistentes

Integración

  • API REST basada en FastAPI
  • Autenticación por X-API-Key para sistemas externos
  • Validación de esquemas en tiempo real

Base de Datos

  • PostgreSQL con esquema relacional optimizado
  • Soporte multi-tenant mediante api_key únicas
  • Índices en campos críticos (fecha, local, mall)

📱 Experiencia de Usuario

Diseño

  • Interfaz moderna con Tailwind CSS
  • Dark mode en sidebar
  • Cards responsive con información compacta
  • Indicadores visuales de estado (crítico/activo/riesgo)

Navegación

Sidebar organizado por secciones:

  • General: Dashboard, IA, Finanzas, Cubo, Auditoría
  • Auditoría IT: Monitor
  • Administración: Mantenimiento, Malls, Usuarios
  • Herramientas: FTP, CSV

Iconografía

  • Lucide React para consistencia visual
  • Códigos de color semánticos (verde=activo, rojo=crítico, amarillo=alerta)
